# 05 - Restricciones

| ID | Restricción | Descripción |
|---|---|---|
| RC01 | Aplicación web | El sistema debe desarrollarse como una aplicación accesible mediante un navegador web. |
| RC02 | Control de versiones | El código fuente debe gestionarse con Git y mantenerse en un repositorio compartido. |
| RC03 | API REST | La comunicación entre el frontend y los servicios debe realizarse mediante una API REST. |
| RC04 | Pasarela de pago | El sistema debe integrarse con una pasarela de pago externa para procesar los pagos. |
| RC05 | Servicio de envío | El sistema debe integrarse con un servicio externo de envío para gestionar la entrega de pedidos. |
| RC06 | ERP | El sistema debe integrarse con el ERP existente para obtener información de productos y stock. |
| RC07 | Facturación | Los comprobantes de pago deben generarse mediante un servicio de facturación externo. |
| RC08 | Documentación | Los documentos del proyecto deben redactarse en Markdown y los diagramas en Mermaid o Draw.io. |
